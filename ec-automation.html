Services

小さく頼みやすい作業に絞っています

初回受注向けに、広すぎるシステム開発ではなく「今ある作業を少し楽にする」範囲を中心にしています。

01 / EC Data

商品情報・価格・在庫の整理

ASINや商品URL、既存の商品リストをもとに、必要な列を整理。取得できる項目と手入力が必要な項目を分けます。

02 / CSV

CSV作成・変換・一括登録補助

モールや管理画面に合わせたCSV列の並び替え、不要文字の削除、カテゴリ・価格・説明文の整形に対応します。

03 / Sheets

スプレッドシート自動化

GASで転記、チェック、メール通知、集計、ステータス管理を自動化。まずは手動確認を残した形で作ります。

04 / Excel VBA

Excel・VBA・マクロ修正

既存マクロの軽微修正、出力形式の変更、帳票作成、列の変換など。添付ファイル確認後に範囲を確定します。

05 / API

API連携の最小構成

PA-API、Keepa、各種APIなどは利用規約とキー管理を確認したうえで、小さな検証用データから進めます。

06 / Docs

手順書・運用メモ

納品後に使えるように、実行手順、注意点、失敗時の見方、列定義を短いメモとして残します。

  • 不要文字、改行、全角半角の整理

Googleスプレッドシート/GAS自動化

  • 運用メモと確認手順を残す

Excel/VBAマクロの軽微修正

既存ファイルの出力形式変更、帳票の向き、列変換、ボタン処理など、範囲を絞って対応します。

  • 既存マクロの動作確認
  • 印刷・帳票・CSV出力の調整
  • 修正箇所と使い方のメモ化

Scope

最初に範囲を分けます

受注後に話が大きくなりすぎないよう、対応できることと慎重に扱うことを明記しています。

向いている案件 ASIN・商品URL・既存CSV・Excel表・スプレッドシートをもとに、取得、整形、転記、チェックを小さく自動化する案件。
最初の進め方 サンプル5〜20件程度で仕様を確認し、列定義・出力形式・確認手順を固めてから広げます。
慎重に扱うもの モール管理画面への直接ログイン、決済、顧客情報、会員情報、認証、医療・患者情報が絡む作業。
対応しない前提 規約違反のスクレイピング、契約前のログイン情報共有、本番データを使った無確認の一括更新。

安全面の考え方 APIキーやパスワードはコードに直接書きません。必要な場合は環境変数やGASプロパティなど、公開されない場所で管理します。

Before Estimate

見積もり前に確認したいこと

ここが分かると、短いやり取りで現実的な金額と納期を出しやすくなります。

  • 元データExcel、CSV、スプレッドシート、商品URL、ASINリストなど、現在使っている形式。
  • 欲しい出力完成後にほしいCSV列、帳票、スプレッドシート、通知内容、サンプル画像。
  • 件数と頻度1回だけなのか、毎日/毎週使うのか。対象件数は10件、100件、1000件のどれに近いか。
  • ログイン・APIログインが必要か、API利用が可能か。契約前にパスワードやAPIキーは受け取りません。
  • 確認方法何を見て「正しい」と判断するか。サンプル5〜20件で先に確認します。
  • 扱う情報顧客情報、決済、認証、医療情報が含まれる場合は、事前に範囲を確認し慎重に進めます。
