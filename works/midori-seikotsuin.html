みどり整骨院Midori Seikotsuin

カテゴリ

技術

HTML / CSS / JavaScript

デプロイ

Cloudflare Pages

ステータス

LIVE

概要

整骨院・接骨院向けの架空デモLPです。植物に囲まれた落ち着いた院内を軸に、「自然に整う、やさしい施術。」というコンセプトで、初めての方でも予約しやすい導線に整えました。

トップだけでなく、施術メニュー、料金、スタッフ、声、アクセス、予約フォームまで用意し、地域ビジネスサイトとしてそのまま提案しやすい構成にしています。

実装した内容

  • ファーストビュー、悩み訴求、選ばれる理由、院内紹介、施術メニュー、流れ、口コミ、FAQ、アクセス、CTA
  • 予約フォームのUI整備。デモのため実送信は行わず、個人情報を保存しない構成
  • 施術メニューの絵文字アイコンを、サイトトーンに合う線画SVGへ差し替え
  • スマホ幅でも横スクロールが出ないように、カード・フォーム・ナビを調整
  • OGP用サムネイルを実画面から撮影して反映

こだわり

  • 医療・施術系として過度に断定しない表現に調整
  • 自然派・清潔感・予約しやすさを優先した配色と余白設計
  • 下層ページまで崩れない共通CSSとして、LP用と既存ページ用のスタイルを整理
  • 個人情報を扱う実装は入れないことで、公開デモとして安全に見せられる形にした
